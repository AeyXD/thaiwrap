## ปัญหาที่ทุกทีมแปลเกมไทยเจอเหมือนกัน

ภาษาไทยเขียนไม่เว้นวรรคระหว่างคำ แต่เอนจินเกมส่วนใหญ่ตัดบรรทัดที่ "ช่องว่าง" — ผลคือซับไทยในเกม
ถูกตัดกลางคำ ล้นกรอบ หรือต้องคอยใส่ <br> มือทีละบรรทัด

## ทางแก้: thaiwrap (โอเพนซอร์ส ฟรี)

ตัดคำไทยด้วยพจนานุกรม 65,758 คำ แล้วแทรกตัวอักษรมองไม่เห็น (ZWSP) ที่รอยต่อคำ
เอนจินก็ตัดบรรทัดถูกจุดเอง **โดยไม่ต้องแก้เกมหรือเอนจินเลย**

- 🔗 โค้ด: https://github.com/AeyXD/thaiwrap
- 🎮 ลองเล่นก่อนได้เลย: https://aeyxd.github.io/thaiwrap/ (พิมพ์ข้อความไทย ลากปรับความกว้างกล่อง)
- 📦 ดาวน์โหลด: ดูที่ Releases — CLI ใช้ได้เลยไม่ต้องติดตั้งอะไร / plugin BepInEx สำหรับเกม Unity

## ใช้ได้กับอะไรบ้าง (ทดสอบ/ตรวจโค้ดจริงแล้ว)

| ชนิดเกม/เอนจิน | สถานะ |
|---|---|
| เกมที่ตัดบรรทัดที่ช่องว่าง (Unity, Unreal ส่วนใหญ่) | ✅ ใช้ได้เลย |
| TextMeshPro (Unity) | ✅ ยืนยันจากซอร์สโค้ด TMP เอง |
| Ren'Py | ✅ ยืนยันจากซอร์สโค้ด |
| Scaleform/Flash (เช่น Witcher 3) | ✅ ใช้ `--break-char hairspace` (พิสูจน์จริงในโมดไทย W3) |
| เอนจินที่ตัดเฉพาะช่องว่างจริง (Aurora เช่น Witcher 1) | ✅ ใช้ `--break-char space` เว้นแบบกลุ่มวลี (พิสูจน์จริงในโมดไทย W1) |
| Godot | ✅ แต่ไม่จำเป็น (ตัดไทยเองได้แล้ว) |
| RPG Maker MZ | ❌ ต้องแก้ที่ตัวเกม/plugin ของมันเอง |

คุณภาพการตัดคำ: จากการวัดบนชุดตัวอย่าง 40 ประโยคเกมเทียบ newmm ได้ precision 100% ในชุดวัด
(ไม่ใช่การรับประกันทุกข้อความ) — อัลกอริทึม DP พัฒนาร่วมกับและพิสูจน์แล้วในโมดซับไทย The Witcher 3 ที่คนใช้จริง

## สำหรับทีมแปล (ใช้กับไฟล์งานแปลโดยตรง)

รองรับไฟล์งานแปลครบ 5 แบบ: **csv/tsv** (ตาราง Excel) · **json** · **po** (gettext) ·
**key=value** (XUnity) · ข้อความเปล่า (.txt)

- ใช้หลัก "ไม่ทำลายไฟล์": นอกจากจุดตัดที่แทรก **ส่วนอื่นคงเดิมทุกไบต์** (BOM, CRLF,
  คอลัมน์ ID, โครงสร้าง JSON, คอมเมนต์) · `--dry-run` ดู diff ทุกบรรทัดก่อนเขียนจริงเสมอ
- เลือกได้ว่าจะแปลงเฉพาะคอลัมน์/field ไหน · ไม่แตะ {placeholder} และแท็ก `<color>` ·
  รันซ้ำไม่พัง (ยกเว้นโหมด space — ดู README)
- **`--normalize`**: แก้คำพิมพ์ผิดที่ editor ดูไม่ออกแต่ทำให้ตัดคำเพี้ยนทั้งย่อหน้า
  (เช่น `เเ` แทน `แ`, `นํ้า` ที่จริงคือ `น้ำ`) — กฎมาจากคำผิดจริงในคลังแปล 176,230 ข้อความ

```bash
thaiwrap ไฟล์แปล.csv --columns thai --dry-run     # ดูก่อน
thaiwrap โฟลเดอร์แปล/ -r                            # ทั้งโฟลเดอร์
```
