# ฉบับร่างโพสต์ประกาศ thaiwrap (ปรับโทน/ช่องทางได้ตามใจ)

---

## ปัญหาที่ทุกทีมแปลเกมไทยเจอเหมือนกัน

ภาษาไทยเขียนไม่เว้นวรรคระหว่างคำ แต่เอนจินเกมส่วนใหญ่ตัดบรรทัดที่ "ชอ่งว่าง" — ผลคือซับไทยในเกม
ถูกตัดกลางคำ ล้นกรอบ หรือต้องคอยใส่ <br> มือทีละบรรทัด

## ทางแก้: thaiwrap (โอเพนซอร์ส ฟรี)

ตัดคำไทยด้วยพจนานุกรม 65,758 คำ แล้วแทรกตัวอักษรมองไม่เห็น (ZWSP) ที่รอยต่อคำ
เอนจินก็ตัดบรรทัดถูกจุดเอง **โดยไม่ต้องแก้เกมหรือเอนจินเลย**

- 🔗 โค้ด: https://github.com/AeyXD/thaiwrap
- 🎮 ลองเล่นก่อนได้เลย: https://aeyxd.github.io/thaiwrap/ (พิมพ์ข้อความไทย ลากปรับความกว้างกล่อง)
- 📦 ดาวน์โหลด: ดูที่ Releases — CLI ใช้ได้เลยไม่ต้องติดตั้งอะไร / plugin BepInEx สำหรับเกม Unity

## ใช้ได้กับอะไรบ้าง (ทดสอบ/ตรวจโค้ดจริงแล้ว)

| ชนิดเกม/เอนจิน | สถานะ |
|---|---|
| เกมที่ตัดบรรทัดที่ช่องว่าง (Unity, Unreal ส่วนใหญ่) | ✅ ใช้ได้เลย |
| TextMeshPro (Unity) | ✅ ยืนยันจากซอร์สโค้ด TMP เอง |
| Ren'Py | ✅ ยืนยันจากซอร์สโค้ด |
| Scaleform/Flash (เช่น Witcher 3) | ✅ ใช้ `--break-char hairspace` (พิสูจน์จริงในโมดไทย W3) |
| Godot | ✅ แต่ไม่จำเป็น (ตัดไทยเองได้แล้ว) |
| RPG Maker MZ | ❌ ต้องแก้ที่ตัวเกม/plugin ของมันเอง |

คุณภาพการตัดคำ: **precision 100%** เทียบ newmm (ทุกจุดตัดที่ใส่ถูกต้อง) — อัลกอริทึม DP
พัฒนาร่วมกับและพิสูจน์แล้วในโมดซับไทย The Witcher 3 ที่คนใช้จริง

## สำหรับทีมแปล (ใช้กับไฟล์งานแปลโดยตรง)

รองรับ csv / tsv / json / po / key=value (XUnity) · มีโหมด dry-run ดู diff ก่อน ·
เลือกได้ว่าจะแปลงเฉพาะคอลัมน์/field ไหน · ไม่แตะ {placeholder} และแท็ก `<color>` ·
BOM/CRLF คงเดิม · รันซ้ำไม่พัง

```bash
thaiwrap data/items.csv --columns thai --dry-run   # ดูก่อน
thaiwrap data/ -r                                   # ทั้งโฟลเดอร์
```
