# thaiwrap

[![CI](https://github.com/AeyXD/thaiwrap/actions/workflows/ci.yml/badge.svg)](https://github.com/AeyXD/thaiwrap/actions/workflows/ci.yml)

ทำให้ข้อความไทยในเกมตัดบรรทัดถูกจุด — **โดยไม่ต้องแก้เกมเลย**

ภาษาไทยเขียนโดยไม่เว้นวรรคระหว่างคำ แต่เอนจินเกมส่วนใหญ่ตัดบรรทัดที่ "ช่องว่าง" เท่านั้น
ผลคือข้อความไทยในเกมถูกตัดกลางคำ หรือยืดยาวล้นกรอบ

thaiwrap แก้ที่ตัวข้อความ: ตัดคำด้วยพจนานุกรมแล้วแทรก **จุดตัดบรรทัดที่มองแทบไม่เห็น**
ไว้ที่รอยต่อระหว่างคำ เอนจินเกมจะตัดบรรทัดตรงจุดนั้นเองโดยอัตโนมัติ

```
"กระบี่อันเป็นเลิศ" → ตัดคำ → กระบี่|อัน|เป็นเลิศ → "กระบี่​อัน​เป็นเลิศ" (แทรกจุดตัด)
```

ใช้ได้ 2 วิธี: **แก้ไฟล์งานแปลล่วงหน้า** ด้วยโปรแกรมบรรทัดคำสั่ง (CLI) หรือ **แก้ตอนเกมกำลังรัน**
ด้วยปลั๊กอิน BepInEx สำหรับเกม Unity — เลือกวิธีที่ตรงกับเกมและ workflow ของคุณ

> 📖 **[คู่มือการใช้งานฉบับเต็ม](docs/MANUAL-TH.md)** — ติดตั้ง · เลือกตัวคั่นตามเอนจิน · ทุกฟอร์แมตและตัวเลือก · โหมดตรวจ QA ·
> สูตรตามงาน (Unity csv · Scaleform · XUnity · .po · GitHub Actions) · แก้ปัญหา
> · 🎮 ลองในเบราว์เซอร์: https://aeyxd.github.io/thaiwrap/

## คุณสมบัติ

**ตัดคำแม่น**
- พจนานุกรม 65,758 คำ ณ v0.14.0 (รวมศัพท์จาก pythainlp + ICU thaidict) + อัลกอริทึม DP optimal segmentation
- คุณภาพจุดตัดเทียบเครื่องมือมาตรฐาน newmm: **precision 1.000** (จุดที่ตัด ไม่เคยตัดผิด)
  recall 0.773, F1 0.872 บนชุดประโยคเกมที่วัดตอน port (v0.4) — *ตัวเลขจากชุดตัวอย่างเพื่อเปรียบเทียบ
  อัลกอริทึม ไม่ใช่การรับประกันทุกข้อความ*
- คำนอกพจนานุกรม (ชื่อเฉพาะ ชื่อตัวละคร) ไม่ถูกตัดแตก — แต่ถ้ายาวเกินไปจะได้จุดตัดระดับก้อนพยางค์ กันข้อความล้นกรอบ
- เพิ่ม/ลบคำเฉพาะเกมได้เองด้วย `words_extra.txt` · วลีห้ามตัดกลางวลีด้วย `nobreak.txt`
- ผ่านการใช้จริง: อัลกอริทึมต้นฉบับใช้กับซับไทย The Witcher 3 ([ThaiW3Setup](https://github.com/AeyXD/ThaiW3Setup))
  และ The Witcher 1 ([ThaiW1Setup](https://github.com/AeyXD/ThaiW1Setup))

**ไม่ทำลายไฟล์งานแปล** — หลักการใหญ่ของโปรเจกต์คือ "อนุรักษ์ของเดิม"
- นอกเหนือจากจุดตัดที่แทรก **ส่วนอื่นของไฟล์คงเดิมทุกไบต์**: การขึ้นบรรทัด (CRLF/LF),
  BOM, คอลัมน์ ID/ชื่อไอเทม (รวม quote เดิมใน CSV เช่น `"001"`), โครงสร้าง JSON, คอมเมนต์ใน .po — ยกเว้นตัวเลือกที่ตั้งใจแก้ตัวอักษร
  ซึ่งปิดไว้เป็น default ทั้งหมด (`--normalize` · `--yamok-nbsp`) และวลีใน `nobreak.txt` (ช่องว่าง → NBSP)
- **ดูก่อนทำจริงเสมอ**: `--dry-run` แสดง diff ของทุกบรรทัดก่อนเขียนอะไรลงไฟล์
- **ไม่เขียนทับต้นฉบับโดยไม่ตั้งใจ**: ไฟล์เดียวเขียนออก stdout หรือไฟล์ที่ระบุด้วย `-o` ·
  โหมดโฟลเดอร์เขียนเป็นไฟล์ใหม่ `ชื่อ.zwsp.ext` · เขียนทับต้องสั่ง `--inplace` (โหมดโฟลเดอร์)
  ซึ่งสร้าง `.bak` ตั้งแต่รอบแรก และไม่ทับไฟล์สำรองเดิมเมื่อรันซ้ำ
- **ปกป้องโค้ดของเกม**: `{placeholder}` เช่น `{ชื่อผู้เล่น}` และแท็ก rich-text
  `<color=red>…</color>`, `<link="…">` ไม่ถูกแทรกจุดตัดเด็ดขาด แม้ข้างในมีตัวอักษรไทย
- รันซ้ำกับไฟล์ที่แปลงแล้ว ไม่เพิ่มจุดตัดซ้ำ (ยกเว้นโหมด `--break-char space`)
- การเข้ารหัสไฟล์ผิด (CP874 ไม่มี BOM · BOM ที่ข้อมูลเสีย) ถูก **ปฏิเสธ** ด้วย exit 2 ไม่แปลงเงียบ ๆ จนตัวอักษรเสีย

**ครบทั้งงานแปลงและงานตรวจ**
- ไฟล์งานแปล 5 แบบ: csv/tsv · json · po · key=value (XUnity) · ข้อความเปล่า — เลือกคอลัมน์/field ได้
- ครอบคลุมเกม 3 ตระกูลเอนจิน — ZWSP / hairspace (Scaleform) / ช่องว่างจริงแบบกลุ่มวลี (Aurora)
- โหมดตรวจสำหรับทีมแปลและ CI: ไฟล์ที่ยังไม่แปลง (`--check`) · placeholder/แท็กพัง (`--placeholders`) ·
  คำแปลวางผิดแถว (`--mispaste`) · คำผิดที่ตัวตรวจคำสะกดจับไม่ได้ (`--stats`) ·
  รวมทุกข้อเป็นรายงาน JSON/HTML ส่งต่อทีมได้ (`--report`)
- แก้คำพิมพ์ผิดที่ทำให้ตัดคำพลาด (`--normalize`) · ไม้ยมกไม่ขึ้นต้นบรรทัด (`--yamok-nbsp`)

**ไม่ต้องติดตั้งอะไรเพิ่ม** — ตัวโปรแกรมเป็นไฟล์เดียวรันได้เลยทั้ง Windows, macOS, Linux
(ดาวน์โหลด zip ที่ [Releases](https://github.com/AeyXD/thaiwrap/releases) หรือใช้จาก [publish/](publish/) ใน repo)
ไม่มี dependency ไม่ต้องมี .NET ในเครื่อง · ส่วนคนอยากแก้โค้ด ใช้ `dotnet` รันจากซอร์สได้ทันที

## เลือกโหมดให้ตรงกับเกมของคุณ

| เกม / เอนจิน | จุดตัดที่ใช้ได้ | วิธีใช้ |
|---|---|---|
| **Unity (TextMeshPro)**, Ren'Py, เอนจินส่วนใหญ่ | ZWSP (U+200B) มองไม่เห็น | default — ใช้เลยไม่ต้องใส่อะไร |
| **Scaleform/Flash** (Witcher 3, เกม AAA จำนวนมาก) | ไม่นับ ZWSP — ต้องใช้ hair space (U+200A) | `--break-char hairspace` + เติม glyph ว่างให้ฟอนต์ · ถ้าเว้นวรรคหน้า ๆ ใส่ `--yamok-nbsp` ([docs/COMPATIBILITY.md](docs/COMPATIBILITY.md)) |
| **เอนจินที่ตัดเฉพาะช่องว่างจริง** (Aurora เช่น Witcher 1) | ไม่นับทั้ง ZWSP และ hair space | `--break-char space` — เว้นช่องว่างจริงแบบกลุ่มวลี (ดูด้านล่างตาราง) |
| **Godot 4** | ตัดไทยเองได้อยู่แล้ว | ไม่จำเป็นต้องใช้ (ใช้ก็ไม่เสียหาย) |
| **RPG Maker MZ** | ตัดระดับตัวอักษร | ZWSP ไม่ช่วย — ต้องแก้ที่ plugin จัดการตัดบรรทัดเอง |

ตารางฉบับเต็มพร้อมหลักฐานจากซอร์สโค้ด/การทดสอบจริง: [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md)

**โหมด `--break-char space`** รวมคำเป็นกลุ่มวลีตามกฎผูกคำไทยแล้วเว้นเฉพาะรอยต่อกลุ่ม (ไม่ใช่ "เว้น วรรค ทุก คำ")
— **รันซ้ำบนไฟล์ที่แปลงแล้วไม่ได้** ต้องรันจากต้นฉบับสะอาดเสมอ · รายละเอียด `--chunk` `--min-len`: [คู่มือ หัวข้อ 3](docs/MANUAL-TH.md#3-เลือกตัวคั่นให้ตรงกับเอนจิน)

## เริ่มใช้งาน

1. ดาวน์โหลด zip ตามเครื่องจาก [Releases](https://github.com/AeyXD/thaiwrap/releases) (Windows / macOS Apple Silicon / Linux)
   แล้วแตกไว้ที่ไหนก็ได้ — ให้โฟลเดอร์ `data/` อยู่ข้างตัวโปรแกรม
2. ดูผลก่อน แล้วค่อยเขียนเป็นไฟล์ใหม่ (ต้นฉบับไม่ถูกแตะ):

```bash
./ThaiWrap.Cli items.csv --columns thai --dry-run        # ดู diff — จุดตัดแสดงเป็น ·
./ThaiWrap.Cli items.csv --columns thai -o items.th.csv  # เขียนไฟล์ใหม่
./ThaiWrap.Cli translations/ -r                          # ทั้งโฟลเดอร์ → สร้าง *.zwsp.* ข้างไฟล์เดิม
./ThaiWrap.Cli translations/ -r --placeholders           # ตรวจ {0} %s <tag> เทียบต้นฉบับ (exit 1 ถ้าพบ)
```

Windows ใช้ `.\ThaiWrap.Cli.exe` · รันจากซอร์สใช้ `dotnet run --project src/ThaiWrap.Cli -- …` ·
macOS ที่ระบบบล็อกโปรแกรม และวิธีอื่น ๆ ดู [คู่มือ หัวข้อ 1](docs/MANUAL-TH.md#1-ติดตั้ง)

ตัวเลือกทั้งหมด: `--help` หรือ [ตารางในคู่มือ หัวข้อ 10](docs/MANUAL-TH.md#10-ตารางตัวเลือกทั้งหมด-และ-exit-code)

## ไฟล์งานแปลที่รองรับ

ทุกแบบใช้หลักการเดียวกัน: **อ่านไฟล์ แปลงเฉพาะข้อความภาษาไทย เขียนกลับโดยส่วนอื่นคงเดิม** —
ไม่ต้องแปลงไฟล์เป็นฟอร์แมตอื่นก่อน และทีมยังเปิดแก้ต่อด้วยเครื่องมือเดิมได้

| รูปแบบ | คือไฟล์อะไร | ตรวจสอบความปลอดภัย |
|---|---|---|
| **CSV / TSV** | ตารางข้อความ (เปิด/แก้ใน Excel ได้ · TSV คั่นด้วยแท็บ) | default แปลงทุกคอลัมน์ — ถ้ามีคอลัมน์ ID/รหัส ใช้ `--columns` เลือกเฉพาะคอลัมน์ไทย |
| **JSON** | ข้อความซ้อนหลายชั้น (setting, dialog tree) | key ไม่ถูกแตะเสมอ · เลือก field ด้วย `--json-keys` (ตามชื่อ key) หรือ `--json-path "/items/*/desc"` (ตามตำแหน่ง) |
| **PO / POT** | ไฟล์แปลมาตรฐาน gettext (นักแปลซอฟต์แวร์ใช้ทั่วไป) | แปลเฉพาะคำแปล (msgstr) — ข้อความต้นทาง (msgid), header, รายการเก่า (#~) ไม่ถูกแตะ |
| **key=value** | รูปแบบ XUnity.AutoTranslator (`ข้อความเดิม=คำแปล`) | ระบุ `-f keyvalue` — คีย์และคอมเมนต์ไม่ถูกแตะ |
| **ข้อความเปล่า** (.txt) | บรรทัดละข้อความ | default · อ่านจาก stdin ได้ด้วย |

รูปแบบไม่ต้องระบุก็ได้ — โปรแกรมเดาจากนามสกุลไฟล์อัตโนมัติ (`-f auto`) · รายละเอียด: [คู่มือ หัวข้อ 5](docs/MANUAL-TH.md#5-ฟอร์แมตไฟล์และการเลือกข้อความที่จะแปลง)

## ไฟล์ของโปรเจกต์ (วางไว้ใช้เอง ไม่ต้องใส่ตัวเลือก)

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `words_extra.txt` | เพิ่มคำเฉพาะเกม (ชื่อตัวละคร สถานที่) · `-คำ` = ลบคำที่ "แย่งพยางค์" เช่น `-ใช้การ` ให้ `ใช้การเล่น` ตัดเป็น `ใช้\|การ\|เล่น` |
| `nobreak.txt` | วลีที่มีช่องว่างแต่ห้ามตัดกลาง (`เดอะ วิทเชอร์`) — ช่องว่างกลางวลีกลายเป็น NBSP |
| `check_allow.txt` | รูปที่ตรวจแล้วว่าถูก ไม่ให้ตัวตรวจคำผิดใน `--stats` รายงานซ้ำ |

วางในโฟลเดอร์ที่รันคำสั่ง (หรือ `data/` ข้าง ๆ) หรือข้างตัวโปรแกรม — ลำดับการหาและรูปแบบไฟล์: [คู่มือ หัวข้อ 6](docs/MANUAL-TH.md#6-ไฟล์ของโปรเจกต์-words_extra--nobreak--check_allow)
· อย่าเพิ่มชื่อเฉพาะของเกมลงพจนานุกรมกลาง `data/words_th.txt` เพราะจะกระทบโปรเจกต์อื่น

## โหมดตรวจ (QA)

| ตัวเลือก | ตรวจอะไร | exit code |
|---|---|---|
| `--check` | ข้อความไทยที่ยังไม่ถูกแทรกจุดตัด — ใส่ใน CI/pre-commit | 1 ถ้าพบ |
| `--placeholders` | `{0}` `%s` `<tag>` ในคำแปลที่หาย เกิน สะกดผิด printf สลับลำดับ หรือแท็กปิดข้ามชั้น เทียบต้นฉบับ (csv/tsv · po · keyvalue) | 1 ถ้าพบ |
| `--mispaste` | คำแปลที่น่าจะ copy จากแถวอื่นมาวาง (csv/tsv) — เกณฑ์จับได้ 31/31 บนคลัง W3 | 0 (ข้อเสนอ) |
| `--stats` | คำนอกพจนานุกรมที่พบบ่อย · รูปพิมพ์ผิด · คำผิดที่ตัวตรวจคำสะกดจับไม่ได้ (ร↔ล · ขา/ข้า · การ/กาล) | ตามปกติ |
| `--report qa.html` | **ทุกข้อข้างบนรวมกัน** เป็นไฟล์ HTML (เปิดในเบราว์เซอร์ ส่งให้ทีมแปล) หรือ `.json` (ให้เครื่องมืออื่นอ่าน) — ไม่แตะไฟล์แปล | 1 ถ้ามีข้อ "ต้องแก้" |

csv/tsv ที่เดาคอลัมน์ต้นฉบับผิด (เช่นมีคอลัมน์หมายเหตุอังกฤษยาว ๆ) ระบุเองด้วย `--source-column en --columns th` ·
ตัวตรวจคำผิดพอร์ตจาก [ThaiW3Setup](https://github.com/AeyXD/ThaiW3Setup) ได้ผลตรงต้นฉบับ Python ทุกจุดบนคลังแปล 176,244 ข้อความ ·
ทดสอบ `--placeholders` กับคลังแปลชุมชน Witcher 3 **แบบดิบ** พบ 312 จุดที่เป็นแท็กพังรูปในข้อมูลดิบ (ไม่ใช่บั๊กในเกมที่ติดตั้ง —
ตัวติดตั้ง ThaiW3Setup ซ่อมแท็กให้ก่อนลงเกม) · กฎและตัวอย่างรายงานทั้งหมด: [คู่มือ หัวข้อ 8](docs/MANUAL-TH.md#8-โหมดตรวจ-qa---check----placeholders----mispaste----stats)

## แก้ตัวอักษรจริง (ปิดไว้เป็น default)

- `--normalize` — ยุบรูปพิมพ์ผิดที่ editor แสดงเหมือนถูกแต่ทำให้ตัดคำเพี้ยนทั้งย่อหน้า: `เเ→แ` · สระ/วรรณยุกต์ซ้อน (สวััสดี) ·
  ลำดับมาร์คผิด · `นํ้า→น้ำ` · วรรณยุกต์หลง — กฎมาจากรูปที่เจอจริงในคลังแปล 176,230 ข้อความ · รูปกำกวมไม่แก้ แต่เตือนใน `--stats`
- `--yamok-nbsp` — ช่องว่างหน้า ๆ (`ต่าง ๆ`) เป็น NBSP กันบรรทัดใหม่ขึ้นต้นด้วย ๆ

ทั้งสองแก้ตัวอักษรของผู้แปล จึงดู `--dry-run` ก่อนเสมอ — [คู่มือ หัวข้อ 7](docs/MANUAL-TH.md#7-ตัวเลือกที่แก้ตัวอักษร---normalize----yamok-nbsp)

## ใช้ตอนเกมรันด้วย BepInEx (Unity)

สำหรับเกม Unity ที่ติด BepInEx 5 ได้ — ปลั๊กอินจะ hook ตอนข้อความถูกแสดงผล ตัดคำให้ทันที
ไม่ต้องแก้ไฟล์ล่วงหน้า:

- รองรับ TextMeshPro และ UGUI Text (ค้นหา component ตอนรัน — DLL เดียวใช้ได้หลายเกม)
- มี cache ไม่ตัดคำซ้ำเมื่อเกมวาดข้อความเดิมทุกเฟรม · ปลอดภัยกับเอฟเฟกต์พิมพ์ทีละตัว
- ปรับการตั้งค่าได้กลางเกม (เปิด/ปิด, `Normalize`, `YamokNbsp`, `MaxWordLength`,
  `UnknownBreakThreshold`) ที่ `BepInEx/config/`
- ใช้ `words_extra.txt` และ `nobreak.txt` ได้เหมือน CLI — วางข้าง `words_th.txt` ในโฟลเดอร์ปลั๊กอิน
- แพ็กพร้อมติดตั้ง + คู่มือไทย: `./tools/package-plugin.sh` → `dist/ThaiWrap/` และ `dist/ThaiWrap-BepInEx.zip`
  (zip เดียวกันแนบอยู่ใน [Releases](https://github.com/AeyXD/thaiwrap/releases))
- **ยังไม่ได้ทดสอบในเกมจริง** — logic ของ filter มีเทสอัตโนมัติ แต่การ hook ในเกม Unity
  ยังรอทดสอบตาม [docs/PLUGIN-TEST-PLAN.md](docs/PLUGIN-TEST-PLAN.md)
- ยังไม่รองรับเกม IL2CPP (BepInEx 6)

## กฎความปลอดภัยของการแทรกจุดตัด

- ไม่แทรกก่อนสระ/วรรณยุกต์ที่ประกอบกับพยัญชนะก่อนหน้า (ั ิ ี ึ ื ุ ู ็ ่ ้ ๊ ๋ ํ ๎)
- ไม่แทรกหลังสระหน้า (เ แ โ ใ ไ) ที่ยังไม่มีพยัญชนะตาม
- ไม่แทรกก่อน ๆ (ไม้ยมก) และ ฯ (ไปยาลน้อย)
- ไม่แทรกทั้งช่วง `{placeholder}` และแท็ก rich-text `<...>` (CLI เปิดเสมอ · ปิดได้เฉพาะตอนใช้เป็น
  library ผ่าน `ThaiWrapOptions.ProtectPlaceholders`)
- ไม่แทรกติดช่องว่างเดิม, ต้น/ท้ายข้อความ, ก่อนเครื่องหมายปิด หรือหลังเครื่องหมายเปิด
- ตัวเลข/อังกฤษ (`25%`, `150/200`, `XP`) คงเป็นก้อนเดียว
- ชื่อเฉพาะ/คำนอกพจนานุกรมที่ยาวไม่เกิน 8 cluster ถือเป็นก้อนเดียว ยาวกว่านั้นจึงยอมให้ตัด
  ระดับ cluster (กันล้นกรอบ · ปรับด้วย `--unknown-threshold`)
